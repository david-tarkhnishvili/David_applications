Portable dorsal-pattern identification app

Darevskia ID

This folder contains the portable browser interface for recognizing individual lizards from dorsal patterns. It launches annotation, matching, and pattern-variation workflows from the local Python app.

This page can open on GitHub Pages, but GitHub Pages cannot run the Python backend. Start launch_web_app.bat or darevskia_web_app.py on your computer first, then use the local browser app.

Open local app Download launcher Portable setup 
python -m pip install -r requirements.txt
launch_web_app.bat

Included workflows

Landmark annotation, five-point curved-belt matching, tripoint and quadrilateral matching, result previews, logs, and pattern-variation summaries.

1. Keep the bundle together

The app needs darevskia_web_app.py, requirements.txt, and the tools folder.

2. Install packages

Run the install command once in the same Python environment used for image analysis.

3. Launch locally

Run launch_web_app.bat, then open http://127.0.0.1:8094/ if the browser does not open.

To make this work as a fully online app, the Python backend must be hosted on a Python-capable server. GitHub Pages only serves static files such as HTML, CSS, and JavaScript.
