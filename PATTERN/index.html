Portable dorsal-pattern identification app

Darevskia ID

This folder contains the portable browser interface for recognizing individual lizards from dorsal patterns. It launches annotation, matching, and pattern-variation workflows from the local Python app.

This web page cannot start a Windows .bat file by itself. First start the Python backend on the computer that stores E:\Darevskia_ID\gallery, then open the app URL. If the backend is not running, the buttons below will show a browser connection error.

Start on this computer

  1. Open File Explorer.
  2. Go to E:\Darevskia_ID\portable_app.
  3. Double-click START_DAREVSKIA_LOCAL.bat for local use, or launch_stationary_backend.bat for online tunnel use.
  4. Leave the black Python window open while using the application.
  5. Then click Open local app or paste your online tunnel URL below.

Included workflows

Landmark annotation, five-point curved-belt matching, tripoint and quadrilateral matching, result previews, logs, and pattern-variation summaries.

1. Start the backend

Double-click START_DAREVSKIA_LOCAL.bat in E:\Darevskia_ID\portable_app.

2. Keep it open

The black Python window is the application server. Closing it stops the app.

3. Open the app

Use http://127.0.0.1:8094/ locally, or your tunnel URL online.

The backend URL can be supplied as ?app=https://your-public-backend or saved in this browser. GitHub Pages remains the entry page; image analysis runs on the stationary computer.
