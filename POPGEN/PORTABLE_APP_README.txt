How to move it to another Windows computer
1. Copy the entire POPGEN folder.
2. Keep these files together in the same folder:
   - index.html
   - styles.css
   - app.js
   - START_POPGEN_WINDOWS.bat
3. On the other computer, double-click START_POPGEN_WINDOWS.bat.

No installation is required.
No internet connection is required.
No Python, R, or server is required.

If the application does not open
1. Right-click START_POPGEN_WINDOWS.bat and choose Open.
2. If Windows security blocks it, choose More info, then Run anyway.
3. Alternatively, open index.html directly in Chrome, Edge, Firefox, or Safari.

Important
Do not copy only index.html. The application also needs styles.css and app.js.

Mobile use
This is a portable browser application, not a native mobile application. It can run in a mobile browser, but the interface is designed for teaching on a laptop or desktop because it contains large tables and graphs.
