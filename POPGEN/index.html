Metapopulation summary

Model formulas

Isolation: Fst = 1 - (1 - 1 / 2Ne)t

Migration equilibrium: Fst = 1 / (1 + 4Nm), using realized migrant counts

Total inbreeding: 1 - Fit = (1 - Fis)(1 - Fst)

Dynamic pair Fst: isolation Fst x migration-equilibrium Fst, with optional indirect paths

Local Fis: Hardy-Weinberg, partial inbreeding, or cumulative drift

Alleles: tracked-allele fitness w = 1 - s, mutation, discrete migration, Wright-Fisher sampling
